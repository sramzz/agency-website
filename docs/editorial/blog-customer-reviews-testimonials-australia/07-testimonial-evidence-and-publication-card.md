# Testimonial evidence and publication card

An original worksheet for **Customer Reviews and Testimonials: What Australian Businesses Should Check Before Publishing**. It records the basis for a publication decision; it does not itself grant rights, supply a legal release or certify compliance.

## 1. Identify the feedback and its purpose

| Field | Your record |
|---|---|
| Internal feedback reference | |
| Reader question this item should help answer | |
| Relevant service/project and context | |
| Source type: direct feedback / third-party platform / other | |
| Original source, date and approved evidence location | |
| Evidence of the person's genuine experience | |
| Original wording or media reference | |
| Any relationship, incentive or other context to disclose | |
| Responsible editor and reviewer | |

Keep unnecessary personal information out of working copies. Do not invent a customer, source or experience to fill a gap. Public visibility alone does not settle the basis for advertising reuse.

## 2. Check meaning and claims

| Field | Your record |
|---|---|
| Proposed final quote/transcript and version | |
| Edits, cuts, translation or transcription from the original | |
| Qualifiers and circumstances that must remain visible | |
| Proposed surrounding heading, caption and placement | |
| Any factual or numerical performance claim | |
| Supporting evidence, dates, units and limitations | |
| What the statement does not establish or promise | |
| Open questions and who will resolve them | |

Customer approval and claim substantiation answer different questions. An authentic statement is not automatically a typical result or a supported advertising promise. Compare the quote and its surrounding message, not just individual words.

## 3. Record the basis and scope of use

| Field | Your record |
|---|---|
| Applicable rights/permission basis and evidence | |
| Person/organisation providing permission and relevant authority | |
| Exact quote version approved, where approval is the basis | |
| Attribution agreed: name, role, business, location or limited attribution | |
| Photo/logo/media rights checked separately where applicable | |
| Channels agreed: website, named pages, advertising or other | |
| Duration, limitations and review conditions, if any | |
| Relevant privacy obligations and handling decision | |
| Platform/API/widget terms and product-specific attribution, if applicable | |
| Contact and process for corrections or changed permission | |

Do not treat permission for one channel as unlimited permission for every campaign. Record uncertainty rather than checking an approval box by assumption. A neutral website-feedback request is not a substitute for following a platform's review-solicitation policy.

## 4. Decide before publishing

| Field | Your record |
|---|---|
| Decision: proceed to final checks / revise / seek evidence / clarify rights / do not publish | |
| Reason and unresolved conditions | |
| Required disclosures and where they will appear | |
| Selection/source/rating description the page will show | |
| Final responsible decision-maker and date | |
| Intended page(s) and version | |

“Selected testimonials” is context, not a cure for a misleading overall impression. Do not invent an aggregate score from selected quotes. Google review collection, website display and Search rich-result eligibility require separate checks.

| Field | Actual evidence |
|---|---|
| Published URL(s), version and actual date | |
| Quote, qualifiers, heading and disclosures checked together | |
| Attribution and scope match the recorded basis | |
| No unintended personal details in screenshots/media | |
| Source link/widget display and current rating information, if used | |

The check concerns what is actually displayed. A draft, permission record or syntactically valid schema does not establish a published result, a legal conclusion or eligibility for review stars.

## 6. Fictional decision exercises

All five cases are teaching premises. They are not customer feedback, permissions, ratings or results from Ranking Rebels. The short text in A/B is invented for the exercise and must remain labelled as such if used in an article or demonstration.

| Case | Supplied situation | Proposed editorial decision | Evidence or correction still needed |
|---|---|---|---|
| A — Clear service experience | A genuine customer, within the fictional premise, supplied “The team explained the revised scope before we approved the quote.” The final words and limited attribution are approved for a named service page; no performance number is claimed | Proceed to final checks within that stated scope | Check the actual surrounding page, rights/context and agreed attribution; no real approval exists here |
| B — Qualifier removed | Original: “The installation took two days once the materials had arrived.” Proposed excerpt removes the condition about materials | Revise and review the final meaning/context | Preserve the condition; do not imply a shorter overall lead time |
| C — Unsupported performance result | Feedback says sales doubled, but period, measure and supporting evidence have not been established | Seek evidence; do not publish it as a supported or typical result | Establish the claim and context or obtain a different authentic statement with an appropriate use basis; do not invent figures |
| D — Public review, unclear reuse | A favourable Google review is visible, but the intended copying method, rights basis and attribution requirements are unresolved | Clarify rights/method before publication | Check the relevant permission or other lawful basis and product/platform conditions; public visibility is not blanket approval |
| E — Selected quotes presented as a full rating | A page features only chosen positive quotes but labels them “all customer reviews” and displays an unexplained average | Revise the representation; do not publish that misleading presentation | Establish genuine source/count/scope; make selection clear without treating a label as an automatic cure |
