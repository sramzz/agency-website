## Verificación técnica y editorial

- **Genuinidad y claims:** el feedback puede aportar perspectiva sin probar resultado típico. El ejercicio conserva la condición temporal. [ACCC claims](https://www.accc.gov.au/business/advertising-and-promotions/false-or-misleading-claims) respalda valorar mensaje global y sustento; la aprobación no se vende como salvoconducto.
- **Permiso y cobertura:** pedir aprobación documentada se identifica como práctica editorial. Se niega un release legal idéntico para toda cita y se limita [APP 6](https://www.oaic.gov.au/privacy/australian-privacy-principles/australian-privacy-principles-guidelines/chapter-6-app-6-use-or-disclosure-of-personal-information) a entidades cubiertas/excepciones, sin hacerlo explicación completa de marketing directo.
- **Reutilización:** distingue visibilidad pública, base de uso y método. No certifica un widget ni transfiere reglas API a toda cita manual. Los términos utilizados corresponden a Australia.
- **Selección:** la etiqueta de testimonios seleccionados no corrige por sí sola una presentación engañosa; tampoco se impone publicar todos los comentarios recibidos.
- **Datos estructurados:** no confunde publicar contenido visible con rich result, no evada la restricción cambiando el tipo y no marca ejercicios como reseñas de RR. Una validación sintáctica no se reporta como elegibilidad.
- **Utilidad y acceso:** las ubicaciones son propuestas, no posiciones ganadoras demostradas. [W3C](https://www.w3.org/WAI/tutorials/carousels/) respalda controles; no se proclama accesibilidad completa por citar una guía.

No hay estadísticas, casos reales, rankings o efectos comerciales inventados que verificar. No se pudo confirmar demanda cuantitativa, inventario completo, material humano, integración o publicación; esos datos no se afirman.
