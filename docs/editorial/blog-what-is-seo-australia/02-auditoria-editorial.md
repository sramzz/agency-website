# Auditoría priorizada

Se usa como base el manuscrito recibido, no una reescritura desde una idea vaga. Prioridad editorial y estado tras los cambios:

| Prioridad | Hallazgo real | Mejora y justificación | Estado |
|---|---|---|---|
| P1 | El ejemplo de Perth aparece después de beneficios y Ads | Se adelanta y se reduce a dos párrafos dirigidos al dueño. Permite entender desde el inicio qué página hace falta. | Aplicado |
| P1 | Intro genérica «This guide explains» y avisos reiterados | Se sustituye por una entrada directa. Se conservan ausencia de garantías y diferencias entre señales y resultados donde afectan a la decisión. | Aplicado |
| P1 | El prompt recibido desconoce publicaciones y cambios previos | Se aplican criterios y artículos reales, con revisión bidireccional de enlaces. Se registra la autorización actual de publicar. | Aplicado |
| P1 | Posible confusión entre rastreo, indexación y visibilidad | Se mantienen las tres etapas y un diagnóstico concreto del acceso frente al contenido. | Conservado y aclarado |
| P1 | Las métricas pueden interpretarse como clientes | Se mantienen key events, clic frente a consulta recibida, consultas adecuadas y límite de atribución. | Conservado |
| P2 | Terminología y plazos ya estaban corregidos | No se inventa un error nuevo: se conserva backlink y el plazo técnico documentado, sin promesa comercial. | Revalidado |
| P2 | La explicación de contenido puede ser abstracta | Se reutilizan las dos búsquedas del manuscrito y se dibuja el propósito diferente de cada página. | Aplicado |
| P2 | SEO local y AI necesitan contexto sin duplicar otras guías | Se mantiene el resumen y se enlazan Maps y SEO/IA, con menciones de vuelta desde ambos. | Aplicado |
| P2 | La imagen opcional del paquete no estaba decidida | Ilustración de paisajismo y gráfico nativo, con estilo de la serie y variantes para móvil. | Preparado e inspeccionado |
| P3 | No hay volumen de keywords ni resultados propios comprobados | No se añaden cifras o experiencia de cliente. No bloquea el artículo informativo. | Límite registrado |

No se añaden garantía de indexación o primer puesto, equivalencia entre clics y sesiones, atribución causal exclusiva, velocidad obligatoria de resultados ni reglas extrapoladas de Google a todas las plataformas de IA. Se mantienen tres tablas y dos listas ordenadas porque permiten comparar información sin alargar el texto.

Humanizer aplicado como paso interno: borrador, lectura crítica y revisión. Se quitaron introducción y transiciones vacías, se variaron los párrafos y se conservaron nombres, hechos, ciudad, enlaces y matices. No se movieron pruebas al producto como si fueran información para sus lectores.
