# Automation prioritisation: local editorial preview

Scope: isolated content-site draft using the current Ranking Rebels public shell, Oswald/Inter/JetBrains Mono, table layout, reading navigation and progress behaviour. The editorial criteria and approved runtime take precedence over older design directions elsewhere in the repository.

Reuse the scoped light/dark reading experiment from blogs 5 and 6. Light: paper #f7f6f2, prose #252a30, headings #12161c, secondary #53606c, links #b51c38. Dark inherits #050609, #c7cbd3, #f8fafc and #94a3b8. preview.css is the owner of this draft’s aliases only; public shared assets remain unchanged.

The hero depicts a human choosing between work cards, in ink and grey with restrained red on off-white paper. Its purpose is selection, not an apparent automated outcome. It contains no readable account information, results, labels or logo. The generated asset and optimised WebP were visually inspected.

Three distinct semantic tables provide the functional visuals. An additional diagram would repeat their work. Retain headings, column scopes, focusable overflow regions and the mobile swipe hint. Essential information stays in the prose and tables. The illustration has descriptive alt text and reserved dimensions.

One manuscript and renderer generate both backgrounds, without new motion, forms, account states or public route changes. Preserve reduced-motion and focus behaviour. Static checks and resource availability are separate from full-page browser QA. This is a proposal awaiting visual selection, not a new globally approved design system.
