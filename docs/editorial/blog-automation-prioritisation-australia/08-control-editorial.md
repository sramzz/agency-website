## Límite de la revisión visual

Se inspeccionaron los recursos gráficos y se comprobaron HTML y disponibilidad. No se realizó una revisión visual de página completa en navegador. Las tablas usan el comportamiento responsivo existente y las dos variantes comparten contenido. Quedan la comprobación visual final, elección y aprobación del usuario antes de publicar o adoptar una plantilla nueva. No se ha simulado una aprobación humana.
