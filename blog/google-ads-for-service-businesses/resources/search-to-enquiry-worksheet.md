# Search-to-enquiry worksheet for a service business

An original educational resource prepared for Ranking Rebels, 21 October 2026. Australian English. The examples below are fictional, not campaign observations, benchmarks or recommendations to spend a particular amount. No advertising account or customer data was used.

Use this worksheet to connect the service you want to sell with the searches, promises and outcomes you need to investigate. It does not configure a campaign or predict which queries a match type will trigger.

## 2. Interpret a search before deciding what to change

Illustration: a fictional residential landscaping business in selected Perth suburbs. Its actual services and coverage would need to be confirmed. A plausible interpretation is not verified intent, and a negative keyword decision must account for its matching rules.

| Hypothetical query | Possible need | Decision to check | Promise and destination | Evidence after contact |
|---|---|---|---|---|
| landscaping quote Perth | Compare a garden project | Include if this work is offered | Project scope, genuine service area and quote process | Suitable project, address and usable contact details |
| garden maintenance Perth | Recurring upkeep | Separate or exclude if not offered | Maintenance page only if that service exists | Requested frequency and capacity |
| landscaping jobs Perth | Employment | Review an employment exclusion for the sales campaign | Do not promise work vacancies through a sales offer | Separate job applications from sales enquiries |
| free landscaping quote Perth | Request a no-charge quote | Retain if the offer really includes it; do not blindly exclude “free” | Explain any material quote conditions | Scope and expectations confirmed |
| DIY garden design | Do the work personally | Consider exclusion if advice/products are outside scope | Do not imply a DIY product is offered | What help is actually requested |
| landscaper for a Perth rental property | Arrange work, possibly from elsewhere | Location setting should reflect how owners buy | Coverage of the property's address | Service address and decision-maker checked |
| cheap landscaper Perth | Compare price | Investigate fit; price language alone does not prove poor quality | Honest scope and quote process, no invented discount | Scope, expectations and commercial fit |

The search terms report provides only part of the query picture. Record which evidence is available, rather than claiming every search is visible. Review available terms together with enquiry outcomes.

## 3. Keep business events distinct

| Event | Evidence required | Owner |
|---|---|---|
| Contact interaction | Measured click or other interaction, labelled accurately | |
| Received enquiry | Message or connected contact recorded by the business | |
| Qualified enquiry | Agreed criteria assessed, with reason/status | |
| New customer | Won-customer definition met and recorded | |

Use agreed statuses such as received, awaiting assessment, qualified, disqualified, quote pending and won or lost. Record a reason for disqualification, for example an unoffered service or an address outside coverage. Keep outcome status separate from qualification: a qualified enquiry may still be lost, and an unresolved enquiry is not automatically disqualified. Adapt these labels to the business rather than assuming they fit every sales process.

Decide how repeat contact about one job is deduplicated. Avoid duplicate tracking imports for the same outcome. Distinguish unresolved enquiries from disqualified enquiries. Do not place names, emails, phone numbers or sensitive customer details in a public copy of this worksheet.

Review the campaign's actual goals and conversion actions, not only the label “primary” or “secondary”. A secondary action in a custom goal can still be used for bidding. Record tracking coverage, known gaps and how later outcomes are associated with the original advertising interaction.

## 4. Compare costs using the same group of enquiries

This is the **same hypothetical example as the article**. All amounts are AUD, excluding GST on a consistent basis. It describes a tracked group whose sales outcomes have had sufficient time to be assessed, not a calendar month's recent leads mixed with older sales.

| Input or result | Example | Your value and evidence |
|---|---|---|
| Media spend associated with the group | 1,500 | |
| Clicks | 150 | |
| Unique received enquiries | 30 | |
| Qualified enquiries, within those 30 | 12 | |
| New customers, from that same group | 3 | |
| Other included campaign management/page costs allocated to the group | 600 | |
| Media ÷ clicks | 10 per click | |
| Media ÷ received enquiries | 50 per enquiry | |
| Media ÷ qualified enquiries | 125 per qualified enquiry | |
| Media ÷ new customers | 500 per attributed new customer | |
| (Media + stated other costs) ÷ new customers | 700 per customer, on this limited cost basis | |

Do not calculate a rate with a zero denominator; report it as unavailable and state the underlying counts. If outcomes are still unresolved, identify the group as provisional. Specify your observation cut-off, follow-up period, attribution approach and missing data.

These measures are not profit, complete company-wide acquisition cost or proof of incremental sales. To assess economics, account for revenue, service delivery costs and other relevant costs. Do not treat a configured lead value as realised revenue.

## 5. Turn observations into an investigation

Record the observation, possible explanation, evidence needed, owner and next review. For example:

| Observation | Investigation | Evidence that would change the decision |
|---|---|---|
| Form clicks rise, but received messages do not | Test delivery and event definitions | Confirmed delivery records or a reproducible failure |
| Many enquiries request an unoffered service | Review queries, ad promise and page scope | A consistent pattern of mismatched requests |
| Suitable enquiries are not quoted | Review responsibility, capacity and follow-up | Recorded reasons and response history |

Changing a budget is not a substitute for identifying the problem. A small sample supports a tentative investigation, not a definitive diagnosis.
