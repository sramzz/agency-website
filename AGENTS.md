# Ranking Rebels

## Blog work

For work that creates, edits or publishes a Ranking Rebels blog, read [the editorial criteria](docs/editorial/criterios-ranking-rebels.md) and [the internal-link inventory](docs/editorial/enlazado-interno.md) first. These preserve the user's decisions that may be absent from a supplied writing prompt.

The user requires every new blog to be reviewed against all existing articles in both directions: new to existing, and existing to new. Check the inventory against the actual blog routes and hub, read the articles, and add contextual links where they help the reader. Do not force every pair to link or impose a link quota.

Update active manuscripts and generated pages together so a later publication preserves the links. Keep the inventory and review record current. When publication is authorised, include the relevant updates to older articles in the same release. If the task is preparation only, keep those updates as draft proposals.

This review is complete when every existing article has been considered in both directions, useful links are implemented or a reason for omission is recorded, and link destinations and the generated HTML are checked. After an authorised publication, verify the links on the served pages before reporting success.
